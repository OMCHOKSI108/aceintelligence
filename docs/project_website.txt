# Ace Intelligence Systems — Website Codebase Architecture & Context

## Project Overview

Ace Intelligence Systems is a marketing/portfolio website for an AI and automation agency startup. The company was founded in 2025 by three AIML students from CHARUSAT University (graduating 2027), headquartered in India. The site is deployed to Vercel at https://aceintelligence.systems.

---

## Configuration Details

### next.config.ts
- Remote image patterns: avatars.githubusercontent.com, miro.medium.com
- CORS headers: Access-Control-Allow-Origin: * on all routes

### tsconfig.json
- Target: ES2017
- Path alias: @/* maps to ./src/*
- Strict mode enabled
- Excludes node_modules and aceintelligence/ (bot project)

### postcss.config.mjs
- Uses @tailwindcss/postcss plugin (Tailwind CSS v4)

### vercel.json
- Standard Vercel Next.js build config

- NEXT_PUBLIC_BOTPRESS_INJECT_URL — Botpress webchat inject script

- Triggers on every push to any branch
- Node 24 + npm ci
- master branch pushes deploy to production

- Requires VERCEL_TOKEN, VERCEL_ORG_ID, VERCEL_PROJECT_ID secrets

## Special Features

### Botpress Chatbot Integration
- Component: BotpressChatbot.tsx — dynamically loads Botpress webchat scripts
- Setup Guide: CHATBOT_SETUP.md — full setup documentation
- Knowledge Base: docs/ace-chatbot-knowledge.md — comprehensive company/product knowledge
- Config: Requires NEXT_PUBLIC_BOTPRESS_INJECT_URL and NEXT_PUBLIC_BOTPRESS_CONFIG_URL env vars
- Behavior: Captures leads (name, email, company, project description, timeline, budget)

### Contact Form with Email Delivery
- Frontend: Client-side form with validation (name, email, phone, company, budget, service, description)
- API: /api/contact route sends HTML-formatted email via Gmail SMTP (Nodemailer) to 3 recipients
- Script: scripts/send-email.js for standalone testing

### 3D Interactive RAG Workflow
- Built with React Three Fiber + @react-three/drei
- 11 interactive nodes representing the RAG pipeline stages
- Hover effects, bobbing animation, edge labels
- OrbitControls for rotate/zoom
- Fallback 2D grid visualization for error/loading states

### Mermaid Architecture Diagrams
- Multi-agent architecture flowchart
- Hallucination defense pipeline visualization
- Rendered server-side using the mermaid library

### Google Translate Integration
- Language switcher in header supporting English, Spanish, French, Chinese
- Custom CSS to hide default Google Translate UI
- Persists language choice in localStorage

### Research Agent Sandbox
- Interactive terminal-style UI simulating 8-agent research pipeline
- Animated step-by-step execution with status indicators
- Simulates real agent names and actions

### SEO Optimization
- Full OpenGraph + Twitter Card metadata
- Schema.org structured data (Organization + WebSite)
- Dynamic sitemap with priority levels
- Robots.txt with disallow rules
- Canonical URLs on all pages
- Google Search Console verification

### Google Analytics & Tag Manager
- GTM: GTM-NVQKSPGF
- GA4: G-LGCLQMBXDC
- Both loaded via next/script with afterInteractive strategy

### Hydration Sanitizer (Development Only)
- Custom script in layout that strips browser extension attributes (e.g., bis_skin_checked) to prevent React hydration mismatches during development

## The aceintelligence/ Directory

This is a Botpress ADK (Agent Development Kit) project — a separate bot project that lives inside the repository but is excluded from the TypeScript build (tsconfig.json excludes it, .gitignore lists it). It contains:
- Agent configuration files (agent.config.ts, agent.json)
- Source code in src/
- Evaluation tests in evals/
- Its own package.json and tsconfig.json

This bot logic is deployed via Botpress Cloud (not through the Next.js app).

---

## The scripts/ Directory

Contains send-email.js — a standalone Node.js script for testing the contact form email delivery. Uses Gmail SMTP with Nodemailer. Sends a formatted HTML email to the 3 team members. Requires GMAIL_SMTP_PASS environment variable.
